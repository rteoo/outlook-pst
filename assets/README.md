# Project artwork

`outlook-pst-icon.png` is the project's original raster icon, used by the root
README. Its transparent outer margin works on light and dark backgrounds.
It depicts an envelope in an archive tray with a search lens.

## Creation

Created with the built-in Image Generation tool on 2026-10-06. The project's
owner supplied SnipVoice and SnipType as style references: rounded dark-blue
tiles, cyan details, subtle depth, and an amber accent. Their marks were not
copied. The output is saved at its native resolution without post-processing;
the README displays it at 128 pixels wide. No Microsoft or Outlook mark is used.

## Prompt

> Use case: logo-brand. Create ONE finished square app/project icon for Outlook
> PST, a local tool to search and export mail archives. The two supplied images
> are STYLE REFERENCES ONLY: SnipVoice and SnipType. Create a NEW identity, do
> not edit or reproduce their microphone, document, or letterform. Match their
> visual family: rounded dark royal-blue/navy tile, polished subtle dimensional
> shading, luminous cyan details, restrained warm amber accent. Subject: a clean
> bright ivory envelope visibly emerging from a cyan archive tray/box, with a
> small amber magnifying-glass ring overlapping the lower-right corner to
> communicate search. Strong readable silhouette, balanced centered composition,
> simple large geometric shapes, friendly precise desktop utility aesthetic.
> Head-on view with gentle depth, crisp edges, no busy glow, no photorealism.
> Square 1024x1024, rounded blue tile takes about 85% of canvas leaving consistent
> transparent outer margins; background outside the tile MUST be genuinely
> transparent. Design to read clearly when displayed at 128px in a GitHub README,
> and work on dark/light backgrounds. No text, no letters, no badges, no Microsoft
> or Outlook logo, no extra versions/contact sheet.
